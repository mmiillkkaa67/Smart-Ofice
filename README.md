# Умный офис

**Номер в журнале:** 8

## Цель проекта
Виртуальный прототип «умного офиса» в GNS3: рабочее место администратора, серверы управления, мониторинга и базы данных, IoT-узел с моделями датчиков. Вентилятор (FAN) в серверной включается автоматически по датчику температуры (TEMP), также им можно управлять вручную с рабочего места.

## Состав стенда (GNS3)
Cisco SW, Cisco RTR, четыре машины РЕД ОС 8 и одна Windows Server 2019.

## Роли устройств
| Устройство | ОС | Роль |
|---|---|---|
| WindowsServer2019-1 (WIN) | Windows Server 2019 | рабочее место администратора |
| REDOS8-1 | РЕД ОС 8 | маршрутизатор между VLAN, выход во внешнюю сеть через Cloud1 |
| CTRL | РЕД ОС 8 | управляющий узел: логика, сбор файлов по SCP |
| MON | РЕД ОС 8 | мониторинг состояния оборудования |
| DB | РЕД ОС 8 | база данных |
| IOT | РЕД ОС 8 | Node-RED: модели датчиков TEMP, HUM и вентилятора FAN |
| Switch1 | Ethernet switch GNS3 | коммутатор, разделяет узлы по VLAN |
| Cloud1 | — | выход во внешнюю сеть |

## Подключения и порты коммутатора
| Порт Switch1 | Узел | Режим | VLAN |
|---|---|---|---|
| 0 (e0) | REDOS8-1 (e0) | dot1q (trunk) | 10, 20, 30, 40 |
| 1 (e1) | WindowsServer2019-1 (e0) | access | 30 |
| 2 (e2) | DB (e0) | access | 10 |
| 3 (e3) | CTRL (e0) | access | 20 |
| 4 (e4) | IOT (e0) | access | 30 |
| 5 (e5) | MON (e0) | access | 40 |

Cloud1 (eth0) подключён к REDOS8-1 (e1).
